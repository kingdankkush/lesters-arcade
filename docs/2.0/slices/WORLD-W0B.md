# WORLD W0b — existing terrain source leases

Default-off terrain source streaming for the current 12,000 × 4,800 six-district world is implemented and tested as a bounded presentation slice. Enable the exact `?areaStreaming=1` switch in the standalone/private Free harness; `?flatTerrain=1` disables it. The existing production portal whitelist does not forward this new switch. Full logical world, nav construction, spawning and rules remain loaded and unchanged. No map, gameplay, version, wallet, contract or deployment change is included.

The lazy layer receives detached camera/view values and existing fixed district/surface metadata. It shares pages between area owners, prefetches 1.5 screens beyond the visible half-viewport and retains two screens for hysteresis. Its catalog is 11 material tiles, 11 fringes and five overlays. Manifest-based full-size reservations total 15,728,640 B; two loads may run concurrently within a 16 MiB reservation cap. Actual successful source pixel dimensions supply separate RGBA estimates. Reservations and pixel estimates do not measure GPU/driver/process residency, mipmaps, decode scratch or peaks.

Successful mobile-variant or fallback URLs carry a private ownership scope. Leaving the final owner unregisters the exact texture, invalidates the static bake and detaches/destroys real Pixi sprites referencing the captured original source before unloading its actual successful URL. The loader verifies cache/wrapper/source ownership and destruction of that original source. Pixi Assets lacks an AbortSignal load API: stale requests finish, remain charged until then and unload without publication. Ambiguous or incomplete disposal retains its reference/reservation and rejects. A throwing status callback cannot stop cleanup; both original lifecycle and callback errors remain observable.

The final source was checked under one owned shared heavy marker. The marker was explicitly released after every job ended. Before/after runtime and browser-witness hashes match in the [closure receipt](../../qa/hmh-world-w0b-closure-20260929.json). Four world/nav/elevation/interaction hashes also match W0a. New tests use current code and real Pixi resources; no Git calls occur at test runtime.
