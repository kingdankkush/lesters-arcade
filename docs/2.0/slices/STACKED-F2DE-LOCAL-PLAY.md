# F2d/e: optional standalone local versus

Playable local Free match behind the exact `stackedLocal=local-v1` portal
switch. The mode menu links to `/stacked/local.html?stackedLocal=local-v1&mode=free`.
The standalone gate requires these unique parameters, no additional parameters
and top-level ownership. Default, Ranked, duplicate and embedded routes deny
before importing the local app or Pixi. This is not the public default.

Two equal-seed boards use the existing frozen match and attack table. The new
driver runs at 60 Hz, caps catch-up at four steps, discards excess debt and
pauses before any step when input loses ownership. It resolves top-out/draw,
resets cleanly for rematches and never sends results, storage or reward writes.
Canonical solo, simulation, verifier, Worker and version sources are unchanged.

Setup supports keyboard plus a standard controller, two standard controllers,
or explicitly selected split keyboard. Device claims are immutable, validated
and disjoint. The two DOM HUDs show hold, next five, score, lines and incoming
rows at readable fixed text sizes. Pause offers two control guides. Results
show each player's statistics. Pattern cues default on. Portrait pauses both
boards and disables Resume until playable dimensions return. At 320px the
dialog scrolls internally; its bottom actions and note are reachable.

The lazy entry owns teardown before either asynchronous boundary. Leaving while
loading prevents a late mount; late handles are destroyed. An aborted listener
group prevents old UI actions from recreating inputs after disposal. A persisted
pageshow reloads once into a fresh setup. The browser exercise for that handler
uses simulated lifecycle events, not an actual browser-cache restoration claim.

Independent Character and World reviews covered deterministic timing, input
loss, old-run/import boundaries and lifecycle cleanup; Art reviewed original UI
captures. The frozen table now has one direct local-only importer. A transitive
parser-based guard rejects canonical entry reachability, missing/invalid imports,
encoded/query paths and forbidden local chain edges. Test fixtures do not use Git.
