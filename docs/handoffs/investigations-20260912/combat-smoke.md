# Investigation: combat-smoke

scripts/hmh-reboot-combat-browser-smoke.mjs is half live, half dead. Live: the URL gates, the state() reader (every dataset key it reads still exists in main.mjs), ready(), the corrected waitForEnemyRoster() (accepts the level-up offer), the autofire wait (lastWeaponFire==='coin-blaster'), the boss-pressure wait (playerHealth<100 lands only via the Liquidator because evidenceSafe blocks enemy and grenade damage but resolveLiquidatorAttack has no invulnerable input), director/boss/debt-collection waits, all world/art/shader/district/reveal/minimap assertions, the KeyG hand-grenade step (KeyG is still the grenade alternate; KeyF primary; right-click too), the touch 'power' tap (power maps to grenade), and the worldTour=bridge flow. Dead: Digit2/3/4 weapon slots, Space fire, KeyE melee, Shift/ShiftLeft dash and the mobile 'weapon' touch button — none of those codes are in InputState.gameplayKeys (only W/A/S/D, arrows, F, G, Escape), so setKey() returns false and the touch button has no element; waits on lastWeaponFire==='scatter-shotgun'/'auto-miner'/'launcher-rig', weaponId==='scatter-shotgun', manual dash displacement and the '#hmhRebootDashStatus' /Dash (active|N seconds)/ regex (the HUD now says DODGING | AUTO DODGE | DODGE Ns, aria-label 'Automatic dodge ...') can never pass. The first red step is desktopSmoke line 164-166; because line 411 runs desktop -> mobile -> worldTour sequentially in one try, mobile and world-tour never execute and .hermes/evidence/hmh-reboot-phase8-combat/ is empty on disk. The shipped runtime exposes enough telemetry to keep every evidence intent using only shipped controls: autofire (lastWeaponFire, firing, aimSource), auto-equip via worldTour=collectible-* cache tours (collectibleLast, weaponId, weaponClipSize, weaponAmmo), automatic reload (weaponStatus, weaponReloadTicksRemaining, #hmhHudWeapon data-state/--reload/data-reload-flash), automatic melee (lastMeleeTick, lastMeleeHits, heroAutomaticAction==='melee' under telemetry=1), automatic dodge (dashReadyTick, dashActive, dashInvulnerable, dashStopReason, #hmhRebootDashStatus text/aria-label/data-ready, heroAutomaticAction==='dodge'), grenade (handGrenades, grenadeCount, activeGrenadeWarnings/Radius/Urgent, lastGrenadeTick/Reason), boss (bossActive, bossPhase, bossHealth, bossPendingTells, bossPendingAttackIds, bossTelegraphPrimitives, bossAttackDrops) and director (directorInsertions/Rejections/LastReason, encounterBand, enemyArchetypes, enemyCount, enemySafetySteps, enemyAttackDrops, enemyDeathVisuals). ## Root cause
The script drives a control model that no longer exists. Cycle 025 (77f81c70) simplified touch to move/aim/power/pause, and the later 'retiring manual combat extras' change (action-map.mjs:81-88 comment; entries table lines 3-10 now lists only moveUp/Down/Left/Right, grenade KeyF, pause Escape; alternates arrows + KeyG) removed fire, melee, dash, weaponSlot and weaponNext from keyboard (keyboardActionRecord hard-codes them false), pointer (input.mjs:117/249 only fire/grenade, and snapshot() at 261-267 forces fire/melee/dash false, weaponNext false), touch (touch-controls.mjs ACTIONS = grenade|pause, TOUCH_CONTROL_SPEC has no 'weapon' button) and gamepad (mapGamepadSnapshot 66-74). InputState.gameplayKeys is built from keyboardCodesForBindings (W/A/S/D, arrows, F, G, Escape); createBrowserInputController line 371 returns early for any other code and setKey line 138 returns false, so page.keyboard.down('Digit2'|'Space'|'KeyE'|'Shift') are silent no-ops. Evidence: desktopSmoke line 164-166 holds Digit2 then Space and waits for dataset.lastWeaponFire === 'scatter-shotgun'; the loadout's activeWeaponId can only change through grantWeaponPickup(select:true) on a weapon-cache pickup (main.mjs:3613) or the evidence pilots (3100-3106), never through input, so the wait times out at Playwright's default 30 s and throws. Line 411 builds the report sequentially inside one try, so mobileSmoke and worldTourSmoke never run (the evidence dir .hermes/evidence/hmh-reboot-phase8-combat/ is empty; the first screenshot would only be taken at line 188 after KeyG). The mobile flow would independently fail at line 283 (count() === 5; four controls exist) and 284 (tapTouchControl 'weapon' has no element). The reload-slice assertions (86c8824e, lines 295-314) are correct against hud.mjs 232/270/279-280 but sit behind the dead Space hold. The dash-status regexes (lines 250, 253, 378) are dead because main.mjs:2467-2468 now renders 'DODGING' | 'AUTO DODGE' | 'DODGE Ns' with aria-label 'Automatic dodge ...'. Note for anyone verifying: the playerHealth < 100 wait at line 155 does pass under evidenceSafe=1 only because the Liquidator's attacks (resolveLiquidatorAttack, main.mjs:4227) ignore invulnerability; enemy (enemy-combat.mjs:211) and grenade (main.mjs:4111) damage are blocked.
