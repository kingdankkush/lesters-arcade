# Investigation: selector-height

## Root cause
Guard semantics: readHeroSelectorEvidence reports documentHeight = document.documentElement.scrollHeight (contract line 18), so the 1,800 pin at smoke line 128 measures the whole guest page, of which only 1,261 px is the selector (evidence.selector.height). Measured HEAD at 390x844 = 1,866 px: nav 242 (sticky, in flow; four 44 px tabs each a full row via styles-arcade-polish.css:1287-1289) + jukebox 142 + 24 margins (position: static at <=720, :1212-1217) + view 1,261 + 16 margin + footer 131 + 18 margin + app padding 16. Timeline (scratchpad harness reproduces Cycle 074's recorded 1,770 exactly when given 3ff5f802's bios with the footer link row hidden): 3ff5f802 = 1,770; 126dd58d bios +22 (Lester's bio grew from 164 to 196 chars = 8 lines; the locked Lester card sets the grid row height) = 1,792; 9ce73720 bios -22 (186 chars = 7 lines) = 1,770; b893962e `.official-footer-links` +96 (five links with min-height 44 wrap to two rows at 390 px: 2x44 + 2 gap + the footer's 6 px row gap) = 1,866; 3e45dfa4 portrait switch +0 (only HERO_SELECTOR_DISPLAY_SCALE 1.4 -> 1, a transform on the fixed 108 px box, and the hmhHeroPortraitFrame keyframes; stage stays 168, rotator 108 in every state). Why the selector is 85+ px fatter than designed: (1) styles-arcade-polish.css:2022-2031 (b50d5aac) target `.hero-card-inner` and `.hero-card-bio`, names that never appear in official-play-routes.mjs (which emits .hero-card/.hero-card-info/.hero-bio) or index.html, so the intended phone padding 16 / gap 10 never applied and cards keep desktop 22 / 18 (measured -37 px when fixed); (2) `#officialCharacterRoster .hero-card-stage { min-height: 168px }` (:2019-2021, ID specificity 1,1,0) beats the <=420 `.hero-card-stage { height: 132px }` (:1296-1299, 0,1,0); 168 was sized for the Cycle 013 1.28x (later 1.4x) transform-scaled sprite, and after 3e45dfa4 set the scale to 1 the 108 px portrait sits under a measured 46 px dead band (-36 px when removed). Additional slack: roster padding-bottom 18 (:2008, -10 at 8 px) and the locked cards' .hero-unlock-progress block (94 px, -14 when compacted).
