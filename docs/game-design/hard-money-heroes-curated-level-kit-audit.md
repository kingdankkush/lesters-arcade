## Visual QA notes

- Level 1 raw contact sheet clearly shows the usable world language: ghost-town buildings, saloon/storefront/gas station landmarks, tents, interiors, road/ground source sheets, ruins, bones, desert props, mushroom/forest props, water/seabed assets, and signs.
- Sliced terrain produced real 128x64 isometric cells. The first visible batch is mostly dirt variants; this is acceptable for the first automated slice pass. Later Level 1 selection should rank curated variants and avoid checkerboard noise.
- Trimmed props removed large transparent canvases from trees and large environment props. The contact sheet shows no obvious over-cropping. Some trees remain large because their actual canopy/shadow footprint is large, not because padding remains.

## Placement grammar for Level 1

The manifest locks the first-pass design grammar:

```text
ground: grass, dirt, sand, rocky, road, water, shore, cliff, interior-floor
props: landmark-building, tree, plant, rock, ruin, camp, sign, loot-prop, hazard-prop
zones: safe-spawn, main-route, secondary-loop, hard-boundary, soft-dressing,
       poi-landmark, open-arena, mini-boss-arena, boss-arena, extraction-zone,
       negative-space
```

## Next implementation step

Use the generated manifest to build the actual authored Level 1 world contract:

1. Define the Level 1 macro route: safe spawn -> broken road -> ghost town -> forest/water loop -> desert camp -> warehouse/gas-station arena -> boss arena -> extraction zone.
2. Assign hard boundaries with water, cliffs, dense trees, ruins, buildings, rock piles, and fence/sign blockers.
3. Define setpieces/POIs:
   - Ghost Saloon / boarded storefront combat lane
   - Dead forest mushroom grove
   - Shoreline or seabed hazard crossing
   - Desert camp / tent loop
   - Warehouse or gas station open arena
   - Boss arena with clear perimeter and extraction read
4. Wire the manifest into runtime scene-object selection only after the authored layout contract exists and tests lock the route/POI grammar.

## Do not regress

- Do not re-open the old 17k all-sprite editor as the main design workflow.
- Do not scatter props randomly. Every prop should support route readability, boundary language, landmark identity, encounter staging, or negative-space composition.
- Do not mix Level 2/3 work into this pass. Level 1 quality is the priority.
