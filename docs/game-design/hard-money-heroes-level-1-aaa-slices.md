# Hard Money Heroes Level 1 AAA route, interactivity, and cohesive art slice

Date: 2026-06-30

## Goal

Begin the next Level 1 quality push after the 8-minute balance pass. This slice does three things together:

1. Turns the 8-minute run into authored campaign acts instead of a flat survival timer.
2. Gives each high-visibility POI at least one tactical interactive object.
3. Starts replacing weak/generic Level 1 props with cohesive final-setpiece assets using one palette and material language.

This is not a final art-complete Level 1. It is the first runtime/data/art layer for the next three implementation slices.

## Cohesive Level 1 art direction

Style id:

```text
level1-crypto-wasteland-cohesive-aaa-v1
```

Palette and readability target:

- dusty ochre roads
- warm weathered timber
- burnt umber shadows
- Litecoin gold accents
- toxic orange mushroom hazard accents
- cool cyan neon/extraction highlights
- chunky dark arcade outlines
- clear isometric footprints

Policy:

> Replace generic placeholder crates, signs, hazards, and road cues in high-visibility POIs with cohesive palette-matched final setpiece assets before adding more random scatter.

## Runtime/data wiring

New pure module:

```text
apps/portal/src/hmh-level-one-aaa-slices.mjs
```

It exposes:

```js
HMH_LEVEL_ONE_AAA_ART_DIRECTION
HMH_LEVEL_ONE_AAA_ROUTE_ACTS
HMH_LEVEL_ONE_POI_INTERACTIVES
HMH_LEVEL_ONE_REPLACEMENT_ASSET_KEYS
aaaLevelOneRouteActs()
aaaLevelOnePoiInteractivesForZone(zoneId)
aaaLevelOneReplacementAssetForRole(zoneId, role)
aaaLevelOneSceneObjectsForDistrict(districtId)
validateLevelOneAaaSlicePlan(...)
```

The curated world contract now attaches:

```js
aaaSlicePlan: HMH_LEVEL_ONE_AAA_SLICE_PLAN
```

The authored scene-object path now consumes the new interactives through:

```js
aaaLevelOneSceneObjectsForDistrict(districtId)
```

This means the objects travel through the existing authored scene-object runtime path instead of living as docs-only design.
